AWebShop – Complete Development Prompt
📌 PROJECT OVERVIEW
AWebShop is the first online marketplace in Uzbekistan where users can buy and sell fully functional websites. The platform features an escrow payment system, a custom token economy (AWC), Telegram bot integration, a comprehensive admin panel, and a premium subscription system.

Domain: https://ttnaceri.github.io/AwebShop/
API Endpoint: https://ttnaceri.github.io/AwebShop/55668576
Deployment: GitHub + Vercel
Custom Domain: To be added after revenue generation

💳 PAYMENT & ESCROW SYSTEM
Option 1: Safe (Escrow)
text
1. Buyer pays → Money goes to Admin
2. Seller sends website to Admin (via GitHub transfer)
3. Admin verifies website
4. Buyer confirms it's the correct website
5. Admin sends website to Buyer
6. Admin sends money to Seller
7. Website automatically removed from WebShop
Option 2: Fast (Direct)
text
1. Buyer pays directly to Seller
2. Seller sends website directly to Buyer
3. Website automatically removed from WebShop
Transaction Statuses
pending → paid → transferred → verified → completed
cancelled • disputed • refunded

Time Limits
Action	            Time Limit
Transfer	        7 days
Verification	    3 days
Auto-Release	    7 days (if buyer doesn't verify)
Dispute Response	3 days
Refund	            5 days
